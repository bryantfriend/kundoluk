Kundoluk Teacher Companion

English guidance and locally saved Excel lesson plans for teachers using Kundoluk. Free in version 0.12.1.

Independent, unofficial extension. Not affiliated with or endorsed by Kundoluk or the Ministry of Education. You review and save school records yourself.

What it does

  • Explains recognized Kyrgyz and Russian interface labels in English.
  • Imports supported Excel lesson plans and assigns worksheets to classes.
  • Previews and fills lesson topics and homework after teacher confirmation.
  • Offers suggestions from locally recorded progress and explicitly captured schedules.

It never presses Save and does not enter grades or attendance. Unknown labels stay in their original language. Site layout changes may require updates.

Install

The Chrome Web Store submission is being prepared. A store installation link will be added after approval.

For trusted development testing, download the project from GitHub, extract it, open chrome://extensions, enable Developer mode, choose Load unpacked and select the extension folder. Refresh Kundoluk and open Lesson companion. Developer installations need manual updates.

Privacy and support

Workbook contents, class assignments, schedules and preferences stay in this Chrome profile. No analytics, advertising, remote translation service or developer-operated server. Keep original workbooks as backups.
