    A little help, when you need it

    Something looks different?

    Chrome says the folder is missing a manifest.

    Extract the ZIP first—you cannot load the ZIP itself. For the release ZIP linked above, select the extracted folder that directly contains manifest.json. If you used GitHub’s Code → Download ZIP instead, choose the extension folder inside the extracted project.

    I don’t see Developer mode or Load unpacked.

    Use desktop Chrome and enter chrome://extensions in its address bar. This guide does not install an extension in mobile Chrome. A school administrator may disable Developer mode or extension installation on managed computers; ask them about approved installation.

    The Lesson companion button is missing.

    Open your authorized teacher account at https://kundoluk.edu.gov.kg/mon. Refresh after installation or an update. Check that the extension is enabled in chrome://extensions. Other Kundoluk routes may not be supported.

    My class isn’t listed, or the wrong curriculum appears.

    Open Manage classes → My classes and lesson plans. Check the school year. Use Add classes from this screen on the visible timetable, scan other weeks as needed, or enter exact subject/class names manually. Check the assigned workbook and worksheet. An upload initially assigns the first worksheet.

    The import has errors or a suggestion is wrong.

    Review the import notes. Use the supported headers, text cells and whole session counts. Choose the correct lesson and session manually if a suggestion is wrong. Captured schedules must include the complete intended date list; duplicate or missing dates require review. A suggestion does not prove a lesson was taught or saved.

    How do I update without losing my saved plans?

    Keep the installed folder in a permanent location. Extract the newer release, replace the files inside that same installed folder, click Reload on the extension’s Chrome card, then refresh Kundoluk. Avoid removing the extension or clearing its storage; those remove saved plans. Keep original workbooks as backups.

    How do I report a problem?

    Open a GitHub issue with your version and a fictional example. Never post student names, passwords, account identifiers or private workbooks. Blur private details in screenshots.
